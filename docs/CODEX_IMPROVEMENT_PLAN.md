# MBD GOAT Improvement Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Improve Mr. Baseball Dynasty across reliability, save safety, worker wiring, gameplay depth, balance, UX, performance, narrative, and test coverage while preserving deterministic simulation and long-save compatibility.

**Architecture:** Treat the web worker as canonical game state, route pages as DTO consumers, `packages/sim-core` as deterministic engine logic, and `packages/contracts` as the save/DTO boundary. Improvements should land in narrow vertical slices: test first, implement in sim-core/worker/UI as needed, then verify targeted and package gates.

**Tech Stack:** TypeScript, React, Vite, Vitest, Comlink worker API, Zustand UI mirror, Zod contracts, Dexie/IndexedDB saves, `pure-rand` deterministic RNG, pnpm/Turbo.

## Non-Negotiables

- No bare `Math.random()` in sim paths.
- Save-state changes require schema version bump, migration, and tests/fixtures.
- Preserve Season 10 save compatibility.
- No new dependencies unless there is a concrete 2-sentence justification.
- Keep changes reviewable; avoid broad refactors unless the task is explicitly about extracting a large file.
- Stage files explicitly if this is moved into a git checkout. Never use `git add -A`.
