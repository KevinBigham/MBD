# Assistant V2 First-Session Flow

## Golden Path

1. Save Hub: choose New Dynasty and land focus on the setup wizard.
2. Day One: finish or quick-start onboarding.
3. Dashboard: read one urgent card before simming.
4. Roster: make the roster legal and inspect OVR before any move.
5. Player Profile: use OVR, floor/current/ceiling, Development, and Scouting before deciding.
6. Scouting: start with Pro Reports in the first session.
7. Finance: check commitments before trades or free-agent offers.
8. Sim: advance in small chunks after one concrete issue is handled.

Draft, Trade, and Free Agency are still explained, but V2 now redirects closed-market first-session actions toward Scouting or Finance until the phase opens.

## Copy Rules

- Default panel copy shows one short first-session cue.
- Deeper strategy remains behind an explicit button.
- Hardcore mode stays available for denser trade/market reading.
- Guidance remains replayable and non-blocking.
