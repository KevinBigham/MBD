# TRUST-QW — Isolated Trust and Clarity Wins

## Objective

Ship only source-confirmed, low-risk clarity fixes that reduce misleading or empty UI without schema, simulation, or new-route work.

## Candidate items

Validate each against live source and include only items that remain real and fit the cut line:

- honest old-save archive-coverage copy using existing metadata;
- label derived mentorship analysis as non-assignable rather than implying control;
- useful invalid/no-game heading;
- explain no-active-save redirect;
- hide setup filters with only one possible value;
- correct stale save-version documentation from the live constant;
- small trust copy defects directly proven by tests/runtime.

## Rules

- Each item should touch at most three production files.
- Drop any item requiring schema, new DTO model, simulation change, event ledger, new route, or broad refactor.
- Do not mix unrelated visual redesign.

## Proof

Targeted rendering/controller tests, route smoke, mobile sanity where touched, full gates. Document each accepted and rejected candidate.

## Done

Every included item is visibly correct, truthful, isolated, and fully tested; no item became a hidden feature slice.
