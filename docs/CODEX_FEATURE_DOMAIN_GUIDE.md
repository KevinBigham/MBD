## Product Shape

Mr. Baseball Dynasty is a local-first browser baseball dynasty simulator. The React app is an operations console over a canonical web-worker game state. `packages/sim-core` owns deterministic baseball, player, roster, economy, acquisition, narrative, and long-memory logic. `packages/contracts` owns serializable save and DTO boundaries. `apps/web/src/workers` adapts runtime state into route-facing DTOs and mutations.

The app is best understood as five layers:

1. Browser shell: Vite/PWA, router, layout, command palette, keyboard shortcuts modal, save recovery, preferences, audio, and toasts.
2. Route features: page-level React surfaces under `apps/web/src/features`.
3. Worker bridge: Comlink API, worker-owned `FullGameState`, snapshot import/export, DTO queries, mutations.
4. Sim core: deterministic game, season, roster, finance, draft, trade, scouting, narrative, and history logic.
5. Contracts/tests: Zod schemas, migration chain, worker tests, route tests, sim-core tests, bundle/perf tests.
